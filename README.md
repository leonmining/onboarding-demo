# SNP Onboarding — reisleiders

Interne onboarding-site voor nieuwe reisleiders bij SNP Natuurreizen.

Open `index.html` in een browser. Geen build nodig — pure HTML/CSS/JS.

## Inhoud
- Welkom & intro
- Over SNP
- Kernwaarden
- Jouw rol als reisleider
- Praktische info (checklist, declaraties, noodprotocol, Leave No Trace, trainingen)
- Tips van collega's
- Interactieve onboarding-quiz (8 vragen)
- Contact
